# Phase 12 — Capstone

> **Classes:** 70–76 | **Estimated Total Time:** ~24 hours

## Phase Description

This phase integrates everything from the previous eleven phases into a complete AI security engineering lifecycle. Learners build a full-featured enterprise AI assistant — with RAG, tools, memory, and multi-user access — and deliberately leave it vulnerable. They then red-team the assistant using techniques from every attack phase, harden it with controls from the defensive phases, add security regression tests and runtime monitoring, produce assurance evidence for governance stakeholders, and present a final security report. The capstone is not an exercise — it is a simulation of the real security engineering process that professionals follow when deploying AI systems in production. Every artifact produced is portfolio-ready.

## Main Outcome

Learners complete a full AI security engineering lifecycle — from building and attacking a system through hardening, testing, monitoring, and assurance — producing portfolio-ready artifacts that demonstrate end-to-end security engineering competency.

## Classes

| Class | Title | Description |
|-------|-------|-------------|
| 70 | Build a Vulnerable Enterprise AI Assistant | Constructs a full-featured AI assistant with RAG, tools, memory, and known vulnerabilities |
| 71 | Red Team the Assistant | Attacks the assistant using techniques from Phases 2–7, documenting every finding |
| 72 | Harden the Assistant | Applies defensive controls from Phase 8 to address each finding from the red team exercise |
| 73 | Add Security Regression Tests | Implements the testing framework from Phase 9 to continuously validate all controls |
| 74 | Add Runtime Monitoring | Deploys the observability stack from Phase 10 to detect and respond to future incidents |
| 75 | Produce Assurance Evidence | Generates governance artifacts from Phase 11 including risk register, assurance case, and framework mappings |
| 76 | Present the Final Security Report | Delivers a complete security assessment to stakeholders with findings, remediations, and residual risk |

## Prerequisites

- Completion of all prior phases (Phases 1–11)
- This is the culminating phase — learners should have mastered all attack, defense, testing, observability, and governance concepts before starting
