# Phase 11 — Governance and Assurance

> **Classes:** 63–69 | **Estimated Total Time:** ~24 hours

## Phase Description

This phase connects technical security work to organizational governance, compliance, and assurance requirements. Security that cannot be demonstrated is security that does not exist for auditors, regulators, or executive leadership. Learners establish governance structures and policies for AI security, maintain a living risk register, and construct structured assurance cases that argue why the system is secure with evidence from every prior phase. The phase maps controls to three major frameworks — ISO 27001, NIST AI RMF, and OWASP LLM Top 10 — showing how the curriculum's control-theoretic approach satisfies each framework's requirements. It culminates in executive reporting: producing security posture reports that translate technical findings into business-risk language that leadership and board audiences can act on.

## Main Outcome

Learners can produce evidence for security leadership and audits — building governance structures, risk registers, assurance cases, and framework mappings that demonstrate security posture to internal and external stakeholders.

## Classes
